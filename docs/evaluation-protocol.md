# Evaluation protocol boundary

Current evaluation includes deterministic core tests, backend integration, fake extraction adapters, tiny synthetic numerical model/calibration experiments and optional native-tree/TreeSHAP/Fairlearn smoke tests. See codex-handoff.md for executed results. No real-data or public benchmark has been run and no trained financial extraction checkpoint exists.

Before downstream models: obtain consented evidence, annotate canonical facts and uncertain fields with source locations, validate inter-reviewer consistency, define temporal train/validation/test splits and preserve availability timestamps. Evaluate extraction independently from reconciliation and predictive performance. Only then evaluate calibration, errors, coverage and protected-group fairness with adequate data. Record actual versions, seeds and results; never use invented numbers or a synthetic fixture score as predictive evidence.

`train_extractor.py` explicitly requires local base checkpoint, task, train/evaluation JSONL, data root, new output and version. It checks financial label/alignment contracts, disjoint sample identities and architecture; runs an explicit torch loss loop and computes heldout loss only from supplied records. `evaluate_extractor.py` computes token-level precision/recall/F1 or mean sample CER from actual supplied prediction pairs. Token-level metrics are not entity-span F1; empty reference CER is undefined. These scripts are scaffolds awaiting annotated data/checkpoints; their existence is not evidence of model training.

`train_risk.py` fits a scoped regularized logistic model, LightGBM or XGBoost on labeled rows and separately fits a calibrator on disjoint heldout sample IDs. Censored rows are excluded. `evaluate_risk.py` requires a third disjoint local test set, verifies artifact/data identity and computes Brier/log loss/reliability data/calibration slope/intercept. Optional separate audit-group input computes offline fairness metrics. `--persist` appends actual report metadata for evaluation API retrieval. No script downloads data, invents predictions or merges unrelated benchmarks. Use applicant-level and temporal separation in addition to the implemented sample-ID checks.

All metrics must identify target, scope, dataset, sample membership, versions, units and limitations. Isotonic sample support gates are minimum research checks, not proof of reliability. Report undefined/small-group rates and Wilson intervals. Equalized-odds difference is computed only when at least two groups have both class-rate denominators. Fairlearn ThresholdOptimizer is OFFLINE RESEARCH ONLY: use a distinct optimization split and evaluate a third disjoint holdout, explicitly provide protected groups and retain randomized prediction seeds. Do not promise parity on future data.

TreeSHAP uses raw binary model margin, declared reference/background and feature definitions. Require base+contributions to equal native target within documented numerical tolerance. Do not label those contributions as calibrated probability, project score or causality. Controlled explanation reasons separately verify evidence/coverage and retain event/source lineage.
